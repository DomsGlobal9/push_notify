Any Flutter app can use the gateway with the push_gateway_client package (repo DomsGlobal9/push_notify, folder clients/flutter/push_gateway_client). SC Boutique already does.

1. Firebase project files

  • Android: in the Firebase project of your Firebase credential, Add app → Android with the exact package name, download google-services.json into android/app/ (or a flavor folder such as android/app/src/prod/), and apply the com.google.gms.google-services Gradle plugin.
  • iOS: Add app → iOS, put GoogleService-Info.plist in ios/Runner/, and in Xcode add the Push Notifications and Background Modes → Remote notifications capabilities.
  • Keep both files out of git; copy them onto each build machine.

2. Packages

{% verbatim %}
dependencies:
  firebase_core: ^4.15.2
  firebase_messaging: ^16.7.1
  push_gateway_client:
    git:
      url: https://github.com/DomsGlobal9/push_notify.git
      path: clients/flutter/push_gateway_client

3. Code

await Firebase.initializeApp();

final push = PushGateway(const PushGatewayConfig(
  baseUrl: 'https://push-notify-7upj.onrender.com',
  publishableKey: 'pk_...',          // the product's publishable key only
  androidPackage: 'com.example.app',
  iosBundleId: 'com.example.app',
));

await push.start();                                  // every launch, after login
await push.signIn(userId: id, userToken: token);     // when the backend sends them
push.opened.listen((m) => router.go(m.data['route'] ?? '/'));
await push.signOut();                                // on logout
{% endverbatim %}

4. Register the app here

Add the package / bundle under Apps for the product. Phones can only register for packages listed there.

5. Android extras

  • Create the notification channel your sends use (e.g. orders) at app start.
  • Set a single-colour status-bar icon (com.google.firebase.messaging.default_notification_icon), or Android shows a white square.
  • Some phones (vivo, Xiaomi, Oppo) block background apps: ask people to allow background activity for the app.
  • Each Play upload needs a higher version code than the last one.

6. Test

  1. Install on a real phone, sign in, allow notifications.
  2. The phone appears under Devices.
  3. Send a test with the app in the background, then tap it.
