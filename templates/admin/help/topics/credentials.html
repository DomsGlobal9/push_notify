Credentials let the gateway talk to Google and Apple on your behalf. You need one Firebase credential for all your Android apps and one Apple credential for all your iOS apps. Secrets are encrypted the moment you save; this dashboard only ever shows the project id or team id afterwards.

Firebase (Android)

  1. Open console.firebase.google.com → your project (one project can hold all your Android apps).
  2. ⚙️ Project settings → Service accounts → Generate new private key → Generate key. A .json file downloads. The language picker on that page does not matter.
  3. Check Cloud Messaging tab: Firebase Cloud Messaging API (V1) shows Enabled.
  4. Here: Credentials → Add. Name it (e.g. firebase-main), provider Firebase Cloud Messaging, open the JSON in a text editor, copy everything and paste it into Service account JSON. Save.
  5. Delete the downloaded file from your computer once a copy is in your password manager.

Apple (iOS)

  1. developer.apple.com → Certificates, Identifiers & Profiles → Keys → +.
  2. Name it, tick Apple Push Notifications service (APNs) (environment: Sandbox & Production), Continue → Register.
  3. Download AuthKey_XXXXXXXXXX.p8. Apple lets you download it only once. Save it safely right away.
  4. Note the Key ID (10 characters, also in the file name) and your Team ID (top right of the developer site).
  5. Here: Credentials → Add, provider Apple Push Notification service, fill Team ID and Key ID, open the .p8 in a text editor and paste all of it including the -----BEGIN PRIVATE KEY----- and -----END PRIVATE KEY----- lines. Save.

Replacing a key

Open the credential, paste the new JSON or .p8, Save. Leaving the secret fields blank keeps the current secret, so you can rename safely. A new secret takes effect on the next send; nothing restarts.

warning
A credential used by an app cannot be deleted. Point the apps at another credential first.

If the Details column says "cannot decrypt"

The server's MASTER_ENCRYPTION_KEY changed. Put the original key back in Render's environment (it should be in your password manager). If it is truly lost, re-enter every credential.
