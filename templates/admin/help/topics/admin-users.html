Admin users are the people who can sign in to this dashboard. They are separate from the users of your apps (those only exist as user ids on devices).

Add a person

  1. Admin users → Add: username and a strong password → Save.
  2. On the next page tick Staff status so they can sign in.
  3. Either tick Superuser status (can do everything) or leave it off and grant only the permissions they need, for example view notification and view device for support staff.
  4. Save and send them the dashboard address and their password over a private channel.

Passwords

  • Your own: user menu (bottom of the sidebar) → Change password.
  • Someone else's: open their user → the password section → Reset password.
  • Locked out of every account: in Render, set ADMIN_USERNAME, ADMIN_PASSWORD and ADMIN_RESET_PASSWORD=true, deploy once, sign in, then remove those three variables.

Good practice

  • One account per person; never share a login.
  • Untick Active to remove someone's access while keeping their history.
  • Use long passwords: this dashboard can message every user of every product.
  • History (top right of any record) shows who changed it and when.
